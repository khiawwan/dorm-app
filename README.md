# หอพักเขียวหวาน - ระบบบริหารจัดการหอพัก

เว็บแอประบบบริหารจัดการหอพัก 14 ห้อง (F1-F7, L1-L7) บันทึกค่าเช่า มิเตอร์ไฟ/น้ำ
สถานะการจ่ายเงิน และค่าใช้จ่ายประจำเดือน พร้อมแดชบอร์ดสรุปรายเดือน/รายปี

- **หน้าแรก (`/`)** — แดชบอร์ดสรุปรายรับ-รายจ่าย สถานะห้องพัก กราฟและตารางรายปี (เปิดดูได้โดยไม่ต้องล็อกอิน)
- **จัดการข้อมูล (`/manage`)** — หน้าสำหรับเจ้าของหอ ต้องล็อกอินก่อนถึงจะเข้าได้ มี 3 แท็บ:
  - **บันทึกรายเดือน** — แก้ไขค่าเช่า มิเตอร์ไฟ/น้ำ สถานะจ่ายเงิน หมายเหตุ และค่าใช้จ่ายประจำเดือน บันทึกอัตโนมัติทุกครั้งที่แก้ไข
  - **ตั้งค่าห้องพัก** — เพิ่ม/ลบ/แก้ไขรหัสห้อง ชั้น ค่าเช่าเริ่มต้น
  - **รายละเอียดห้องพัก** — การ์ดของแต่ละห้อง อัปโหลดรูปห้อง และบันทึกรายการของใช้ในห้อง (เตียงนอน ตู้เสื้อผ้า พัดลม ทีวี ฯลฯ)

## การเข้าสู่ระบบ

หน้า "จัดการข้อมูล" (`/manage`) และ API ที่ใช้แก้ไขข้อมูล (`/api/rooms`, `/api/records`, `/api/expenses`, `/api/room-items`)
ต้องล็อกอินก่อนถึงจะเข้าใช้งานได้ ส่วนหน้าแรก (แดชบอร์ด) และรูปห้องที่อัปโหลดไว้ (`/api/uploads/...`)
ยังเปิดดูได้แบบสาธารณะ (ไม่ต้องล็อกอินเพื่อดูรูป)

ค่าเริ่มต้น (ตั้งไว้ในโค้ด ใช้งานได้ทันทีโดยไม่ต้องตั้งค่าอะไรเพิ่ม):

- ชื่อผู้ใช้: `admin`
- รหัสผ่าน: `saharut@kw`

**เพื่อความปลอดภัยเมื่อ deploy ขึ้นสาธารณะ** ควรเปลี่ยนค่าเหล่านี้ผ่าน environment variables แทนการใช้ค่าเริ่มต้น
(ไฟล์ `lib/auth.ts` เก็บ credentials แบบ hardcode ไว้เป็นค่าสำรอง ถ้ามีคนอ่านซอร์สโค้ดจะเห็นรหัสผ่านได้):

```bash
ADMIN_USERNAME=admin
ADMIN_PASSWORD=รหัสผ่านใหม่ที่คาดเดายาก
AUTH_SECRET=สตริงสุ่มยาวๆ_สำหรับเซ็นชื่อ_session_cookie
```

ตั้งค่าเหล่านี้ในไฟล์ `.env.local` (สำหรับรันในเครื่อง) หรือผ่านตัวแปรสภาพแวดล้อมของแพลตฟอร์ม deploy
(Docker/Railway/Render ฯลฯ) — ระบบยืนยันตัวตนแบบนี้เหมาะกับผู้ใช้คนเดียว (เจ้าของหอ) เท่านั้น
ไม่ได้มี rate-limiting ป้องกันการเดารหัสผ่านซ้ำๆ ดังนั้นควรตั้งรหัสผ่านที่คาดเดายากและ deploy ผ่าน HTTPS เสมอ

## เทคโนโลยีที่ใช้

- Next.js 16 (App Router) + TypeScript
- SQLite ผ่านโมดูล `node:sqlite` ที่มากับ Node.js เอง (ไม่ต้องคอมไพล์ native module ใดๆ)
  เก็บข้อมูลเป็นไฟล์เดียวที่ `data/dorm.db`
- Tailwind CSS + ฟอนต์ [Prompt](https://fonts.google.com/specimen/Prompt) (โหลดผ่าน `next/font/google`)
- ไอคอนจาก [lucide-react](https://lucide.dev/)
- รูปห้องที่อัปโหลดเก็บเป็นไฟล์ที่ `data/uploads/` (โฟลเดอร์เดียวกับฐานข้อมูล ถูก volume เดียวกันคุ้มครองตอน deploy)

> ต้องใช้ **Node.js เวอร์ชัน 22.5 ขึ้นไป** (แนะนำ Node.js 22 LTS รุ่นล่าสุด หรือ Node 24 ขึ้นไป)
> เพราะใช้โมดูล `node:sqlite` ที่ enable โดย default ตั้งแต่ Node เวอร์ชันใหม่ๆ
> ถ้าใช้ Node 22.5–22.11 (patch เก่า) แล้วเจอ error ว่า sqlite เป็น experimental
> ให้รันด้วย `NODE_OPTIONS=--experimental-sqlite npm run dev` แทน หรืออัปเดต Node เป็นรุ่นล่าสุด

## โครงสร้างข้อมูล

- `rooms` — รายชื่อห้อง (F1-F7, L1-L7), ห้อง F1 ตั้งค่า `is_owner=1` (ห้องเจ้าของหอ)
- `monthly_records` — ข้อมูลรายเดือนต่อห้อง (ค่าเช่า, มิเตอร์ไฟก่อน/หลัง, มิเตอร์น้ำก่อน/หลัง,
  ราคาต่อหน่วย, สถานะจ่ายเงิน, วันที่ชำระ, หมายเหตุ)
- `monthly_expenses` — ค่าใช้จ่ายรายเดือน (ค่าน้ำ/ไฟจริงที่จ่าย, ค่าเน็ตหอ/บ้าน, ค่าซ่อมบำรุง,
  ให้พ่อ, ให้แม่+พี่, อื่นๆ)
- `room_items` — รายการของใช้ในแต่ละห้อง (ชื่อ, จำนวน) แสดงในแท็บ "รายละเอียดห้องพัก"
- `rooms.photo_path` — path ของรูปห้อง (ถ้ามี) ชี้ไปยังไฟล์ใน `data/uploads/`

เมื่อเปิดดูเดือนใหม่ที่ยังไม่มีข้อมูล ระบบจะสร้างแถวให้อัตโนมัติ โดยดึงเลขมิเตอร์ "หลัง"
ของเดือนก่อนหน้ามาเป็นเลขมิเตอร์ "ก่อน" ของเดือนใหม่ให้เลย (เหมือนที่ทำในชีตเดิม)

## เริ่มต้นใช้งาน (พัฒนาในเครื่อง)

1. ติดตั้ง [Node.js](https://nodejs.org/) เวอร์ชัน 22 LTS ขึ้นไป (หรือ Node 24 ขึ้นไป)
2. ติดตั้ง dependencies:

```bash
npm install
```

3. รันเซิร์ฟเวอร์สำหรับพัฒนา:

```bash
npm run dev
```

4. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

ข้อมูลจะถูกเก็บไว้ที่ `data/dorm.db` โดยอัตโนมัติ (สร้างตารางและห้อง 14 ห้องให้ตอนรันครั้งแรก)

## Deploy ขึ้นเซิร์ฟเวอร์/คลาวด์

แอปนี้ใช้ SQLite แบบไฟล์ (ผ่าน `node:sqlite`) จึงต้อง deploy บนแพลตฟอร์มที่มี **persistent disk**
(ดิสก์ที่ข้อมูลไม่หายเมื่อรีสตาร์ท) เช่น VPS ทั่วไป, Railway, Render, Fly.io (พร้อม volume)
**ไม่แนะนำ Vercel** เพราะเป็น serverless ไฟล์ระบบเป็นแบบชั่วคราว ข้อมูลจะหายเมื่อ deploy ใหม่

### วิธีที่ 1: ใช้ Docker (แนะนำ)

```bash
docker compose up -d --build
```

จะรันแอปที่พอร์ต 3000 และเก็บฐานข้อมูลไว้ใน Docker volume ชื่อ `dorm-data`
(ข้อมูลจะไม่หายแม้ลบ container แล้วสร้างใหม่)

ตั้งค่า reverse proxy (เช่น Nginx, Caddy) พร้อม HTTPS ต่อหน้าพอร์ต 3000 เสมอเมื่อ deploy ขึ้นสาธารณะ
(แอปมีระบบล็อกอินในตัวแล้ว แต่รหัสผ่านจะถูกส่งผ่านเครือข่ายจริง ต้องมี HTTPS ป้องกันการดักฟัง)
อย่าลืมตั้งค่า `ADMIN_PASSWORD` และ `AUTH_SECRET` ผ่าน environment variables ตามหัวข้อ "การเข้าสู่ระบบ" ด้านบน

### วิธีที่ 2: รันตรงบน VPS ด้วย Node.js

```bash
npm install
npm run build
DB_PATH=/path/to/persistent/dorm.db npm start
```

แนะนำให้ใช้ [pm2](https://pm2.keymetrics.io/) หรือ systemd เพื่อให้แอปรันค้างและ restart อัตโนมัติ

### สำรองข้อมูล (Backup)

ฐานข้อมูลทั้งหมดอยู่ในไฟล์เดียว คัดลอกไฟล์นี้ (และโฟลเดอร์ `data/uploads/` ถ้ามีรูปห้อง) เพื่อสำรองข้อมูล:

```bash
cp data/dorm.db backup/dorm-$(date +%Y%m%d).db
cp -r data/uploads backup/uploads-$(date +%Y%m%d)
```

(ถ้าใช้ Docker ให้ `docker compose exec dorm-app` หรือ mount volume ออกมาคัดลอก)

## หมายเหตุเรื่องปี

ระบบใช้ปี พ.ศ. (เช่น 2569) เป็นตัวเลขจัดกลุ่มข้อมูลรายปี/รายเดือน ไม่มีการแปลงปฏิทิน
ส่วนวันที่ชำระเงินใช้ปฏิทินสากล (ค.ศ.) ตามปกติของ input วันที่ในเบราว์เซอร์
